para usar a lista ordenada é só usar o ol e dentro dele o li para por os elementos

  1. carro
  2. moto
  3. caminhao
  4. onibus

os tipos das listas ordenadas são 5

tipo 1 numera as listas, o A deixa com letras maiusculas, o a deixa minusculas e o I em numeros romanos maicusulas e i em minusculas

ol type= "I", por exemplo

  1. carro
  2. moto
  3. caminhao
  4. onibus

usando o start no ol, faz uma contagem

por exemplo se eu usar start="10", os elementos vao ser numerados de 10 para frente

  1. carro
  2. moto
    1. moto azul
    2. moto rosa
  3. caminhao
  4. onibus

usando o ol dentro do li, você acaba fazendo uma lista dentro de uma lista
