Tabelas comparativas de linguagens e frameworks

tipo nome descrição vantagens desvantagens
Linguagem de marcação HTML Define a estrutura e o conteúdo das páginas. Fácil de aprender; todos os navegadores o entendem; leve e rápido. Sozinho não cria comportamento (estático); depende de CSS e JavaScript.
Linguagem de estilo CSS Controla cores, fontes e layout das páginas HTML. Separa conteúdo e aparência; mesmo estilo em várias páginas; layout responsivo. Pode ficar complexo em projetos grandes; não tem lógica de programação.
Linguagem de programação JavaScript Dá comportamento às páginas e também roda no servidor com Node.js. Roda direto no navegador; mesma linguagem no front e no back; ecossistema enorme. Tipagem fraca e dinâmica; erros só aparecem na execução; código no cliente fica visível.
Superconjunto do JavaScript TypeScript JavaScript com tipos estáticos, compilado para JavaScript puro. Detecta erros antes de rodar; melhor suporte do editor; ajuda em projetos grandes. Exige compilar para JavaScript; mais código e configuração; é preciso saber JavaScript antes.
Linguagem de programação Python Linguagem de uso geral, usada em back-end, dados, automação e IA. Sintaxe simples e legível; ecossistema amplo; código aberto e comunidade grande. Mais lento que linguagens compiladas; não roda no navegador; GIL limita o paralelismo.
Linguagem de programação PHP Linguagem de servidor criada para a web, base do WordPress. Muitos profissionais e material; conecta fácil a bancos de dados; muito usada. Popularidade em queda relativa; segurança depende de como é usado; menos versátil fora da web.

Frameworks

framework nome descrição vantagens desvantagens
Biblioteca React Monta interfaces com componentes reutilizáveis (js). Componentes reutilizáveis; DOM virtual (react otimiza o processo de atualização da interface); comunidade enorme; compatibilidade entre plataformas. Não impõe estrutura; JSX (extensão da sintaxe para o js) exige base em JS; mudanças entre versões.
Framework Angular Framework completo do Google para aplicações grandes, em TypeScript. Rotas, formulários e HTTP incluídos; TypeScript por padrão; apoio de longo prazo do Google. Curva de aprendizado alta; mais código repetitivo; pacotes maiores.
Framework Vue.js Framework para interfaces, conhecido pela simplicidade. recursos extras limitados, excesso de flexibilidade, comunidade restrita. Adoção menor que React e Angular; menos recursos de terceiros; flexibilidade pode gerar padrões diferentes.
Meta-framework (React) Next.js Utiliza linguagem ts/js, ela possui integração robusta com a implantação na borda da rede ecossistema vasto; excelente implementação do vercel; regeneração estática incremental (o que permite dados em tempo quase real com desempenho estático). App Router e componentes de servidor são complexos; melhor desempenho atrelado à Vercel; atualizações frequentes (pode gerar atrito com as versões antigas).
Meta-framework (Vue) Nuxt back-end construido sobre o Vue.js, abstrai a maioria das configs no gerenciamento de dados assíncronos, middleware e roteamento. SEO melhor para SPAs; gera sites estáticos; divisão automática de código. Comunidade menor que a do Next.js; depuração mais difícil; SSR com muito tráfego pode pesar no servidor.
Ambiente de execução Node.js Executa JavaScript fora do navegador, no servidor. Rápido e escalável; custo benefício; tratamentos de erros. Programação assíncrona exige cuidado; biblioteca padrão enxuta; ruim para tarefas pesadas de CPU.
Framework (Python) Django estrutura web Python de alto nível que incentiva o desenvolvimento rápido e o design limpo e pragmático. Muitos recursos prontos; projeto dividido em apps; cache; organização e formulários. Pesado para projetos simples e curva de aprendizado inicial.
Framework (PHP) Laravel Framework PHP com sintaxe expressiva e muitos recursos prontos. Sintaxe clara; autenticação, filas e migrações prontas; comunidade grande. versões antigas difíceis de atualizar; mais lento que linguagens compiladas e suporte limitado.
Framework (Java) Spring Boot Simplifica criar aplicações Spring prontas para rodar. Configuração automática; roda como .jar com servidor embutido; grande comunidade. Estilo opinativo, menos controle; curva de aprendizado da autoconfiguração; pacotes grandes.
Framework (C#) ASP.NET Core Framework da Microsoft para web e APIs, multiplataforma. Multiplataforma e código aberto; bom desempenho; modular e pronto para nuvem. Curva de aprendizado; bibliotecas do .NET Framework antigo podem não funcionar; comunidade menor.
Framework (Ruby) Ruby on Rails Prioriza convenções e rapidez de desenvolvimento. Produtivo para lançar projetos rápido; código legível; comunidade ativa. Menos flexível; mais lento que outras opções; atualizar versões antigas é difícil.
